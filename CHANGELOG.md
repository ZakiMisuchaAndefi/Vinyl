# Changelog

Semua perubahan penting pada proyek **Vinyl** dicatat di sini. Format mengikuti [Keep a Changelog](https://keepachangelog.com/id-ID/1.1.0/) dan penomoran versi memakai [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Ditambahkan
- Antarmuka dua bahasa (English dan Indonesia) dengan pilihan bahasa di Pengaturan → Tampilan dan setup awal, default English, serta format tanggal, durasi, dan pengurutan yang mengikuti bahasa aktif.
- Info lisensi **GPL-3.0-or-later**, kode sumber, dan pemberitahuan pihak ketiga di Tentang serta berkas lisensi di bundel desktop.
- Dokumentasi lisensi dan kontribusi komunitas, template GitHub, Dependabot, dan konfigurasi repo.
- Header SPDX pada sumber proyek serta pemeriksaan CI ringan untuk sintaks JavaScript.

## [1.1.0] - 2026-11-23

### Diubah
- Nomor versi aplikasi dinaikkan ke 1.1.0; tidak ada perubahan aplikasi lain yang tercatat setelah v1.0.0.

## [1.0.0] - 2026-11-23

### Ditambahkan
- Pemutar musik web vanilla JavaScript dengan pencarian dan streaming YouTube, katalog FLAC lossless, lirik sinkron dan romanisasi.
- Unduhan audio langsung, perpustakaan lokal untuk MP3/FLAC/M4A/WAV/OGG, radio otomatis, antrean, timer tidur, tema, dan pintasan keyboard.
- Aplikasi desktop Electron untuk Windows dan macOS, pembaruan lewat GitHub Releases, dukungan PWA, onboarding, Audio Lab, dan clean URL.

### Diubah
- Pengaturan, tema, dan tampilan responsif dikembangkan untuk pengalaman web dan desktop.

### Diperbaiki
- Alur rilis Windows/macOS, tampilan mobile, dan fallback saat pemuatan media gagal.
